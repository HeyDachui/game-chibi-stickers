# 《永恒之塔2》Steam服升级攻略流程分享

升级按“推进主线 → 做沿途地区任务和封印副本 → 强化装备、点守护力 → 继续主线”的顺序走。

## 1—10级：先完成升格，再拿第一批强化材料

**天族**从伊斯塔尔城堡跟英雄任务走到晨之军团。约5级出现“雏鸟之翼”时，进升格空间完成任务，取得翅膀。到10级继续做“晨之军团”“全副武装”，穿上任务给的初始装备。

**魔族**从伊斯夏尔根跟英雄任务走向阿尔特盖德。约6级出现“展开你的羽翼”时先做升格；到10级完成安全避难所附近的“生存物资”“收集基础物资”，补齐初始装备。

两边到10级后，打开地图，清路线附近已开放的封印副本，拿首次通关奖励。先把空装备槽补上，再用强化石给武器和落后的部位做低等级强化；守护力结晶留着点面板。拿完首次奖励就继续主线。

## 10—25级：解锁守护力、烙印和远征

1. 继续英雄主线。天族从坎塔斯谷推进到贝尔特伦要塞废墟，魔族继续清阿尔特盖德的营地、墓地和遗迹。
2. 约12级打开守护力面板后，把已有结晶投入当前可解锁的节点。以后每清完一批封印副本或地区任务，再打开面板补一次节点。
3. 路上遇到地区任务就顺手完成。它们除了经验，还给守护力结晶、守护者标志或背包扩充。觉醒进度停住时，点开守护者量表，看缺的是剧情、地区任务、驻地还是封印副本，再去补那一项。
4. 到15、20、25级附近，分别清当前区域新开放的封印副本首次奖励。需要强化腰带时，打开本阵营据点奖励，找到腰带强化卷轴对应的据点，再沿该据点路线做任务。
5. 约23级取得烙印后，打开技能栏装上适合职业的烙印。

远征和奥德能量开放后，准备练多个角色的玩家可以切换下一个角色，让已解锁角色先积累能量。

## 25—40级：把封印材料转成实际战力

天族主线经过阿乌莱乌祭坛、祖米翁村与净化山，约37级走到火之神殿剧情，再进入猩红森林。魔族沿诺尔尼议会、圣树、钢锤工坊与伊敦湖任务线走。

这个阶段每进新区按四步处理：**接英雄任务 → 做同路地区任务 → 清30、35、40级附近新开放的封印副本首次奖励 → 回城用掉强化石和守护力结晶**。强化先补多个落后的槽位。过渡装备换得快，不用为了把一件装备冲高而耗光材料。

每日副本开放后，先手动打一场，查看右侧增益并尽量提高得分；强化石奖励跟分数有关。打出满意的记录后再用立即完成功能。火之神殿等剧情副本打不过时，先检查武器强化、守护力节点、烙印和食物／卷轴增益，再重进。

## 40级后：完成当前主线，再把资源投向长期部位

继续清英雄任务与觉醒缺项，直到主线结束。接下来打开远征界面，看探险和征服的入场条件，先打已经够条件的难度。装分不足时，依次检查空槽、低等级装备、尚未领取的封印首次奖励、尚未点的守护力节点和未强化的腰带。

到45级后的基础养成阶段，腰带可按这条顺序做：

1. 基础腰带强化到 **+10**。
2. 通过物质变换升级为稀有品质，再强化到 **+10**。
3. 继续变换到唯一品质，再强化到 **+10**。

腰带材料沿据点路线取得。到唯一品质+10后先停，转去做守护力、万神殿和深渊饰品。再选两枚适合职业的符文，各强化到 **+1** 后装备，合计约增加80装备评分。尝试+2及以上，失败可能损毁整枚符文；先完成两枚+1即可。

## 想靠多角色清周本：升级顺序另排

1. 先把计划长期玩的角色逐个推进到远征与奥德能量开启，开一个就切下一个。
2. 回到主力角色，继续推到当前主线终点，清掉它已有的副本门票与需要使用的奥德能量。
3. 依次推进第二、第三个角色。角色做主线时，其他已开启远征的角色继续积累能量。
4. 周刷新前，逐角色查看远征次数和奥德能量。缺装备就打远征／征服并开对应宝箱；缺强化石、神石就打超越并开对应宝箱。领完一个角色的目标奖励，再切下一个。
