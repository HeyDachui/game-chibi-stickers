# 《永恒之塔2》Steam服开荒收益：角色、奥德和周本怎么排

先给准备长期玩的角色解锁远征和奥德能量，再推进主力角色。每周按角色清副本、开需要的宝箱，把可交易材料放到市场。

## 第一步：先把准备长期玩的角色开到远征

1. 用第一个角色跟主线走，直到远征和奥德能量开放。
2. 暂停第一个角色，切第二个角色，重复到远征和奥德开放。计划练几个，就先开几个。
3. 回到主力角色，把主线、守护力和装备推起来；其他已开启远征的角色在这段时间积累奥德能量。
4. 主力角色完成当前主线后，先用掉它已到手的副本门票与准备投入的能量，再依次推进其他角色。

## 第二步：每周先整理能量与次数，再选副本

每周第一次上线，逐角色打开远征、奥德能量、物质变换与物资置换，按下面顺序处理：

1. 打开物质变换，找到奥德能量石，把本周已开放且材料够用的份额做出来；再去物资置换和商店，分别检查账号限购与角色限购的能量来源。
2. 查看这个角色的奥德、门票和奖励次数，再看目标副本开一次宝箱要消耗多少能量。
3. 要制作装备的材料和装备，就去远征／征服开对应宝箱；要强化石、神石，就去超越开对应宝箱。先确定要拿的奖励，再投入奥德。
4. 打完一个角色，领取目标奖励，再切下一个角色。

## 第三步：把树古、日常和采集放进空档

**树古活动**先看当天可进的小游戏与钥匙。领奖前检查物品的绑定标记：绑定装备留给自己或分身，可交易材料再放市场。奖励若要在随机装备与守护力结晶之间选，先拿结晶，回去点守护力节点。

**每日副本**先手动打一场，查看增益、把得分打高。强化石等奖励跟得分走；打出满意成绩后再用立即完成功能。每周清掉觉醒、讨伐和噩梦的可用次数。

**采集和制作**等入口开放后再接。靠近资源按F采集，积累精气萃取等级，再把专用技能点投到速度和成功率。材料到手后，先分角色绑定、账号绑定和可上架；绑定材料留给自己的装备制作。打开制作列表选定要做的成品，记下缺少的材料和制作费用，再和市场上的同一件成品比价。若补料成本已高于成品价，就出售可交易材料或直接买成品。

## 第四步：上架之前，先处理两件事

1. **先看交易入口。** Steam服不能玩家直接交易。上架走市场，先确认当前账号有市场使用权限。
2. **想卖的装备先别穿。** 未刻印装备首次穿戴会进行灵魂刻印，刻印后无法交易。掉到可能出售的装备，先看绑定状态和市场价格，再决定自用还是上架。
